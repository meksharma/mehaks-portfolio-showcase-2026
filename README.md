# Mehak’s Portfolio Showcase 2026

A personal portfolio website for Mehak Sharma, a product designer focused on
trustworthy AI experiences, design systems, and thoughtful interaction design.

## Portfolio Preview

This repository contains the portfolio experience currently in development. It
brings together Mehak's profile, design philosophy, experience, and selected
product design work in a responsive, interactive website.

### Featured Work

- **Summarize experience in Outlook Mobile** — A Microsoft case study exploring
	how AI-generated summaries can help people understand long email threads more
	quickly and confidently.
- Additional case studies are being prepared as the portfolio evolves.

### Portfolio Sections

- About and professional background
- Design philosophy and working principles
- Selected product design case studies
- Contact and professional links

## Local Preview

Open `index.html` in a browser to view the portfolio. No build step or external
dependencies are required.

The public portfolio is still in development. GitHub Pages is currently
disabled for this repository.
